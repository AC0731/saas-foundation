# Screenshots

Portfolio screenshots for SaaS Foundation.

## Recommended Files

Add these screenshots before sharing the repository publicly:

- landing-page.png
- auth-page.png
- free-dashboard.png
- pro-dashboard-billing.png
- delete-confirm-modal.png
- stripe-customer-portal.png

## Screenshot Guidelines

- Use a desktop browser.
- Use a clean browser window.
- Hide bookmarks if they look messy.
- Do not show real secrets.
- Do not show real payment details.
- Do not show private customer information.
- Prefer 1440px width or a similar desktop resolution.
- Keep screenshots consistent in size when possible.

## Suggested Capture Flow

1. Open the landing page and save `landing-page.png`.
2. Open `/auth/signin` and save `auth-page.png`.
3. Sign in as a Free user and save `free-dashboard.png`.
4. Upgrade or use a Pro test user and save `pro-dashboard-billing.png`.
5. Open the delete confirmation modal and save `delete-confirm-modal.png`.
6. Open Stripe Customer Portal in test mode and save `stripe-customer-portal.png`.
